## Пример использования

```python
@tracer
def factorial(n):
    if n <= 1:
        return 1

    return n * factorial(n - 1)


factorial(4)
```

Пример вывода:

```text
-> factorial(4)
    -> factorial(3)
        -> factorial(2)
            -> factorial(1)
            <- factorial(1) = 1
        <- factorial(2) = 2
    <- factorial(3) = 6
<- factorial(4) = 24
```

По трассировке видно две стадии работы рекурсии.

Сначала стек вызовов увеличивается:

```text
factorial(4)
    factorial(3)
        factorial(2)
            factorial(1)
```

После достижения базового случая стек начинает раскручиваться обратно:

```text
factorial(1) -> 1
factorial(2) -> 2
factorial(3) -> 6
factorial(4) -> 24
```

## Тесты

Тесты проверяют, что применение декоратора не изменяет результат работы исходной функции.

### Тест факториала

```python
from tracer import tracer


@tracer
def factorial(n):
    if n <= 1:
        return 1

    return n * factorial(n - 1)


assert factorial(1) == 1
assert factorial(2) == 2
assert factorial(5) == 120
```

### Тест рекурсивной суммы

```python
@tracer
def sum_to_n(n):
    if n == 0:
        return 0

    return n + sum_to_n(n - 1)


assert sum_to_n(0) == 0
assert sum_to_n(1) == 1
assert sum_to_n(5) == 15
assert sum_to_n(10) == 55
```

### Тест алгоритма Евклида

Этот тест также проверяет работу декоратора с функцией, принимающей несколько аргументов.

```python
@tracer
def gcd(a, b):
    if b == 0:
        return a

    return gcd(b, a % b)


assert gcd(12, 8) == 4
assert gcd(48, 18) == 6
assert gcd(17, 5) == 1
```

### Тест Фибоначчи

Фибоначчи показывает работу декоратора с разветвлённой рекурсией.

```python
@tracer
def fibonacci(n):
    if n <= 1:
        return n

    return fibonacci(n - 1) + fibonacci(n - 2)


assert fibonacci(0) == 0
assert fibonacci(1) == 1
assert fibonacci(5) == 5
assert fibonacci(6) == 8
```

## Что проверяют тесты

Тесты покрывают:

- базовый случай рекурсии;
- несколько уровней рекурсивных вызовов;
- возврат числового результата;
- функции с одним аргументом;
- функции с несколькими аргументами;
- линейную рекурсию;
- разветвлённую рекурсию.

Кроме результата функции, при запуске тестов в консоли будет отображаться трассировка каждого рекурсивного вызова.

## Оценка сложности

Сам декоратор не изменяет асимптотическую сложность исходного алгоритма.

Для каждого вызова функции дополнительно выполняются:

- вывод сообщения о входе;
- изменение глубины;
- вывод сообщения о возврате.

Если исходная функция делает `m` рекурсивных вызовов, декоратор также обрабатывает `m` вызовов.

Сам декоратор хранит только текущую глубину рекурсии, поэтому дополнительное состояние занимает:

```text
O(1)
```

При этом сама рекурсивная функция использует стек вызовов, размер которого зависит от максимальной глубины рекурсии.
