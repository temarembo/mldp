# AVL Tree

## Задача

Реализовать класс AVL-дерева с поддержкой операций:

- вставка элемента;
- удаление элемента;
- поиск элемента.

AVL-дерево должно сохранять свойства бинарного дерева поиска и автоматически балансироваться после вставки и удаления.

---

## Что такое AVL-дерево

AVL — это самобалансирующееся бинарное дерево поиска.

Для каждого узла выполняются два условия.

Свойство BST:

```text
все значения в левом поддереве < значение узла
все значения в правом поддереве > значение узла
```

Кроме этого, дерево должно оставаться сбалансированным по высоте.

Для каждого узла вычисляется коэффициент баланса:

```text
balance = height(left) - height(right)
```

Допустимые значения:

```text
-1, 0, 1
```

Если значение выходит за этот диапазон, дерево необходимо перестроить с помощью поворотов.

---

## Структура узла

Каждый узел хранит:

```text
value
left
right
height
```

`value` — значение узла.

`left` и `right` — ссылки на левое и правое поддеревья.

`height` — высота поддерева с корнем в данном узле.

Высота листа равна:

```text
1
```

Высота пустого поддерева считается равной:

```text
0
```

Высота любого другого узла вычисляется как:

```text
1 + max(height(left), height(right))
```

---

## Вставка

Вставка сначала выполняется так же, как в обычном бинарном дереве поиска.

Если значение меньше текущего:

```text
идём влево
```

Если больше:

```text
идём вправо
```

Если соответствующего узла нет, создаётся новый `Node`.

После вставки рекурсия возвращается обратно вверх по дереву.

На каждом уровне:

1. обновляется высота узла;
2. вычисляется коэффициент баланса;
3. при необходимости выполняется поворот.

Например, последовательно вставим:

```text
10, 20, 30
```

Обычное BST получилось бы таким:

```text
10
  \
   20
     \
      30
```

У корня `10` правое поддерево стало слишком высоким.

После балансировки AVL преобразует дерево:

```text
    20
   /  \
  10   30
```

---

## Коэффициент баланса

Для каждого узла вычисляется:

```text
height(left) - height(right)
```

Например:

```text
      30
     /
    20
   /
  10
```

Для узла `30`:

```text
left_height = 2
right_height = 0

balance = 2
```

Так как:

```text
2 > 1
```

узел несбалансирован.

---

## Повороты

Для восстановления баланса используются четыре случая.

### LL — Left Left

Дерево:

```text
      30
     /
    20
   /
  10
```

Нужно выполнить правый поворот вокруг `30`.

Результат:

```text
    20
   /  \
  10   30
```

---

### RR — Right Right

Дерево:

```text
10
  \
   20
     \
      30
```

Нужно выполнить левый поворот вокруг `10`.

Результат:

```text
    20
   /  \
  10   30
```

---

### LR — Left Right

Дерево:

```text
      30
     /
    10
      \
       20
```

Сначала выполняется левый поворот вокруг `10`:

```text
      30
     /
    20
   /
  10
```

Затем правый поворот вокруг `30`:

```text
    20
   /  \
  10   30
```

---

### RL — Right Left

Дерево:

```text
10
  \
   30
   /
  20
```

Сначала выполняется правый поворот вокруг `30`:

```text
10
  \
   20
     \
      30
```

Затем левый поворот вокруг `10`:

```text
    20
   /  \
  10   30
```

---

## Балансировка

После изменения дерева вызывается функция балансировки.

Алгоритм:

```text
1. обновить height
2. вычислить balance factor
3. определить тип дисбаланса
4. выполнить нужный поворот
5. вернуть новый корень поддерева
```

Важно возвращать новый корень, потому что после поворота корень поддерева может измениться.

Например:

```text
      30
     /
    20
   /
  10
```

после поворота корнем этого участка становится уже:

```text
20
```

---

## Поиск

Поиск работает так же, как в обычном BST.

Пусть нужно найти `25`:

```text
        20
       /  \
     10    30
          /
         25
```

Сравниваем значение с текущим узлом:

```text
25 > 20 → идём вправо
25 < 30 → идём влево
25 == 25 → элемент найден
```

Если во время поиска достигается `None`, элемента в дереве нет.

---

## Удаление

Удаление сначала выполняется по правилам обычного BST.

Есть три основных случая.

### Узел без детей

```text
10
```

Такой узел просто удаляется.

---

### Узел с одним ребёнком

```text
10
  \
   20
```

После удаления `10` его место занимает:

```text
20
```

---

### Узел с двумя детьми

Например:

```text
      20
     /  \
   10    30
        /
       25
```

Для удаления `20` выбирается следующий элемент в порядке сортировки — минимальный элемент правого поддерева.

В данном случае:

```text
25
```

Значение `25` переносится в удаляемый узел, после чего исходный узел `25` удаляется из правого поддерева.

После удаления, как и после вставки:

```text
обновляются высоты
проверяется баланс
при необходимости выполняются повороты
```

---

## Inorder

Метод `inorder` не является обязательной частью задания, но используется для удобной проверки дерева.

Для корректного BST обход:

```text
Left → Node → Right
```

должен возвращать значения в отсортированном порядке.

Например:

```text
        20
       /  \
     10    30
```

результат:

```text
[10, 20, 30]
```

## Визуализация вставки

Рассмотрим последовательность:

```text
30, 10, 20
```

После вставки `30`:

```text
30
```

После вставки `10`:

```text
  30
 /
10
```

После вставки `20`:

```text
  30
 /
10
  \
   20
```

Получился случай `Left Right`.

Сначала выполняется левый поворот:

```text
   30
  /
 20
 /
10
```

Затем правый:

```text
   20
  /  \
10    30
```

После балансировки:

```text
balance(20) = 0
```

## Оценка сложности

AVL-дерево гарантирует, что его высота остаётся:

```text
O(log n)
```

Поэтому основные операции выполняются за:

```text
search  — O(log n)
insert  — O(log n)
delete  — O(log n)
```

Поворот дерева изменяет фиксированное количество ссылок и выполняется за:

```text
O(1)
```

Рекурсивные операции вставки и удаления используют стек глубиной:

```text
O(log n)
```

## Тесты

### LL rotation

```python
tree = AVL()

tree.insert(30)
tree.insert(20)
tree.insert(10)

assert tree.root.value == 20
assert tree.inorder() == [10, 20, 30]
```

Проверяется правый поворот.

---

### RR rotation

```python
tree = AVL()

tree.insert(10)

tree.insert(30)

assert tree.root.value == 20
assert tree.inorder() == [10, 20, 30]
```

Проверяется левый поворот.

---

tree = AVL()

tree.insert(30)

tree.insert(20)

assert tree.root.value == 20
assert tree.inorder() == [10, 20, 30]
```

```

---

### Поиск

```python
tree = AVL()

for value in [20, 10, 30, 5, 15, 25, 40]:
    tree.insert(value)

assert tree.search(15) is True
assert tree.search(40) is True
assert tree.search(100) is False
```

Проверяется поиск существующих и отсутствующего элемента.

---

### Удаление листа

```python
tree.delete(5)

assert tree.search(5) is False
assert tree.inorder() == [10, 15, 20, 25, 30, 40]
```

Проверяется удаление узла без детей.

---

### Удаление узла с одним ребёнком

```python
tree.delete(10)

assert tree.search(10) is False
assert tree.inorder() == [15, 20, 25, 30, 40]
```

---

### Удаление узла с двумя детьми

```python
tree.delete(30)

assert tree.search(30) is False
assert tree.inorder() == [15, 20, 25, 40]
```

---

### Удаление корня

```python
tree.delete(20)

assert tree.search(20) is False
assert tree.inorder() == [15, 25, 40]
```

---

### Дубликаты

В данной реализации дубликаты не добавляются.

```python
tree = AVL()

tree.insert(10)
tree.insert(10)

assert tree.inorder() == [10]
```
