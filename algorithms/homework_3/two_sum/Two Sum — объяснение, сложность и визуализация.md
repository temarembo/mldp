### Объяснение решения

Нужно найти два элемента массива, сумма которых равна `k`, и вернуть их индексы.

Вместо перебора всех пар используется словарь `seen`.

В словаре хранятся уже просмотренные элементы массива:

```python
seen = {
    значение: индекс
}
```

Для каждого текущего элемента `num` вычисляется число, которого не хватает до суммы `k`:

```python
target = k - num
```

Если `target` уже есть в словаре, значит ранее был найден элемент, который вместе с текущим даёт сумму `k`.

Тогда можно сразу вернуть два индекса:

```python
return seen[target], i
```

Если нужного числа в словаре ещё нет, текущий элемент сохраняется:

```python
seen[num] = i
```

---

### Почему алгоритм корректен

Для каждого элемента `num` алгоритм ищет ранее просмотренный элемент со значением:

```text
k - num
```

Если такой элемент найден, то:

```text
num + (k - num) = k
```

Следовательно, найденная пара удовлетворяет условию задачи.

Словарь содержит только элементы, которые находились раньше текущего, поэтому один и тот же элемент массива не используется дважды.

Так как по условию гарантируется ровно одна подходящая пара, первый найденный результат и является ответом.

---

### Важный порядок действий

Сначала выполняется проверка:

```python
if target in seen:
```

и только после этого:

```python
seen[num] = i
```

Это важно для случаев вроде:

```text
arr = [5, 5]
k = 10
```

На первом элементе `5` словарь ещё пуст, поэтому сам элемент не может использоваться дважды.

После этого первый `5` сохраняется:

```text
seen = {5: 0}
```

На втором `5` нужное значение `5` уже находится в словаре, поэтому возвращаются индексы:

```text
0 1
```

---

### Оценка сложности

Пусть `n` — количество элементов массива.

Алгоритм проходит по массиву один раз:

```text
O(n)
```

Проверка наличия элемента в словаре и добавление в словарь в среднем выполняются за:

```text
O(1)
```

Поэтому итоговая временная сложность:

```text
O(n)
```

В худшем случае в словаре может храниться до `n` элементов.

Поэтому дополнительная память:

```text
O(n)
```

### Визуализация работы алгоритма

Рассмотрим пример:

```text
arr = [1, 3, 4, 10]
k = 7
```

Изначально:

```text
seen = {}
```

Дальше:

| `i` | `num` | `target = k - num` | Есть `target` в `seen`? | `seen` после шага |
|---:|---:|---:|:---:|---|
| 0 | 1 | 6 | нет | `{1: 0}` |
| 1 | 3 | 4 | нет | `{1: 0, 3: 1}` |
| 2 | 4 | 3 | да | поиск завершён |

На шаге `i = 2`:

```text
num = 4
target = 3
```

В словаре уже есть:

```text
3 -> индекс 1
```

Следовательно:

```text
arr[1] + arr[2] = 3 + 4 = 7
```

Ответ:

```text
1 2
```
