### Объяснение решения

Анаграммы состоят из одинаковых букв в одинаковом количестве, но буквы могут находиться в разном порядке.

Например:

```text
eat
tea
ate
```

После сортировки букв каждого слова получится:

```text
eat -> aet
tea -> aet
ate -> aet
```

То есть все анаграммы после сортировки имеют одинаковое представление.

Поэтому используется словарь `groups`, где:

```text
ключ — отсортированные буквы слова
значение — список всех слов с таким ключом
```

Например, для входа:

```python
["eat", "tea", "tan", "ate", "nat", "bat"]
```

словарь постепенно примет вид:

```python
{
    "aet": ["eat", "tea", "ate"],
    "ant": ["tan", "nat"],
    "abt": ["bat"]
}
```

В конце возвращаются только значения словаря:

```python
list(groups.values())
```

---

### Почему алгоритм корректен

Если два слова являются анаграммами, они содержат одинаковые буквы с одинаковым количеством повторений.

После сортировки букв такие слова обязательно превращаются в одинаковую строку.

Например:

```text
aab -> aab
aba -> aab
baa -> aab
```

Следовательно, все анаграммы получают одинаковый ключ и попадают в одну группу.

Если два слова не являются анаграммами, их набор букв отличается, поэтому после сортировки будут получены разные ключи, и слова попадут в разные группы.

Таким образом, каждая группа содержит только анаграммы и включает все слова, являющиеся анаграммами друг друга.

---

### Оценка сложности

Пусть:

```text
n — количество слов
m — максимальная длина одного слова
```

Для каждого слова выполняется сортировка его букв.

Сортировка слова длины `m` занимает:

```text
O(m log m)
```

Для `n` слов общая временная сложность:

```text
O(n * m log m)
```

Словарь хранит все слова и ключи, поэтому дополнительная память:

```text
O(n * m)
```

### Визуализация работы алгоритма

Рассмотрим вход:

```python
["eat", "tea", "tan", "ate", "nat", "bat"]
```

Изначально:

```python
groups = {}
```

Дальше:

| Слово | Отсортированное слово | Состояние группы               |
| ----- | --------------------- | ------------------------------ |
| `eat` | `aet`                 | `"aet": ["eat"]`               |
| `tea` | `aet`                 | `"aet": ["eat", "tea"]`        |
| `tan` | `ant`                 | `"ant": ["tan"]`               |
| `ate` | `aet`                 | `"aet": ["eat", "tea", "ate"]` |
| `nat` | `ant`                 | `"ant": ["tan", "nat"]`        |
| `bat` | `abt`                 | `"abt": ["bat"]`               |

Итоговый словарь:

```python
{
    "aet": ["eat", "tea", "ate"],
    "ant": ["tan", "nat"],
    "abt": ["bat"]
}
```

После получения значений словаря результат будет содержать группы:

```python
[
    ["eat", "tea", "ate"],
    ["tan", "nat"],
    ["bat"]
]
```

Порядок групп не важен, если условие отдельно его не задаёт.

### Тесты

Для удобства тестирования результат нормализуется:

```python
def normalize(groups):
    return sorted([sorted(group) for group in groups])
```

Тесты:

```python
assert normalize(
    anagrams(["eat", "tea", "tan", "ate", "nat", "bat"])
) == normalize([
    ["bat"],
    ["nat", "tan"],
    ["ate", "eat", "tea"]
])

assert normalize(
    anagrams(["abc", "bca", "cab"])
) == normalize([
    ["abc", "bca", "cab"]
])

assert normalize(
    anagrams(["abc", "def", "ghi"])
) == normalize([
    ["abc"],
    ["def"],
    ["ghi"]
])

assert normalize(
    anagrams(["aab", "aba", "baa", "abc"])
) == normalize([
    ["aab", "aba", "baa"],
    ["abc"]
])

assert normalize(
    anagrams(["hello"])
) == normalize([
    ["hello"]
])

assert normalize(
    anagrams([])
) == []

assert normalize(
    anagrams(["", "", "a"])
) == normalize([
    ["", ""],
    ["a"]
])
```

Тесты проверяют:

- пример из условия;
- случай, когда все слова являются анаграммами;
- случай, когда анаграмм вообще нет;
- слова с повторяющимися буквами;
- список из одного слова;
- пустой список;
- пустые строки.
