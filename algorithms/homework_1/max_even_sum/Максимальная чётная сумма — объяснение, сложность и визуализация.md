### Объяснение решения

На вход функция получает строку с положительными целыми числами, разделёнными пробелами.

Сначала строка преобразуется в список целых чисел:

```python
nums_list = [int(num) for num in nums.split()]
```

После этого вычисляется сумма всех элементов массива:

```python
sum_all = sum(nums_list)
```

Так как все числа положительные, выгодно сохранить в сумме как можно больше элементов.

Если общая сумма `sum_all` уже чётная, это и есть максимальная возможная чётная сумма, потому что добавление любых дополнительных элементов уже невозможно — мы и так использовали весь массив.

Если общая сумма нечётная, чтобы сделать её чётной, нужно убрать одно нечётное число. Удаление чётного числа не изменит нечётность суммы.

Чтобы получить максимально возможный результат, нужно убрать минимальное нечётное число. Поэтому во время прохода по массиву алгоритм запоминает наименьший нечётный элемент в переменной `min_odd`.

В конце:

- если `sum_all` чётная — возвращается `sum_all`;
- если `sum_all` нечётная — возвращается `sum_all - min_odd`.

---

### Почему алгоритм корректен

Если сумма всех элементов чётная, она максимальна, потому что все элементы положительные и уже включены в сумму.

Если сумма всех элементов нечётная, для изменения её чётности необходимо убрать нечётное число.

Так как все числа положительные, уменьшать сумму нужно как можно меньше. Поэтому выгоднее всего убрать минимальный нечётный элемент.

После вычитания нечётного числа из нечётной суммы получается чётная сумма, а выбор минимального нечётного числа делает эту сумму максимально возможной.

---

### Оценка сложности

Пусть `n` — количество элементов массива.

Преобразование входной строки в список занимает:

```text
O(n)
```

Вычисление суммы всех элементов занимает:

```text
O(n)
```

Поиск минимального нечётного элемента также выполняется одним проходом по массиву:

```text
O(n)
```

Поэтому общая временная сложность:

```text
O(n)
```

Дополнительная память требуется для списка `nums_list`, содержащего все элементы:

```text
O(n)
```

Остальные переменные используют постоянное количество памяти.

### Визуализация работы алгоритма

Рассмотрим пример:

```text
1 3 4 5 6
```

После преобразования строки:

```text
nums_list = [1, 3, 4, 5, 6]
```

Общая сумма:

```text
sum_all = 1 + 3 + 4 + 5 + 6 = 19
```

Сумма нечётная, поэтому нужно найти минимальный нечётный элемент.

| Шаг | Текущий элемент | Нечётный? | `min_odd` |
|---:|---:|:---:|---:|
| 1 | 1 | да | 1 |
| 2 | 3 | да | 1 |
| 3 | 4 | нет | 1 |
| 4 | 5 | да | 1 |
| 5 | 6 | нет | 1 |

Минимальный нечётный элемент:

```text
min_odd = 1
```

Так как исходная сумма нечётная:

```text
19 - 1 = 18
```

Получаем:

```text
18
```

Это максимальная чётная сумма.

- массив из одного чётного числа;
- массив только из чётных чисел;
- массив только из нечётных чисел;
- случай с несколькими нечётными элементами;
- корректный выбор минимального нечётного элемента.
