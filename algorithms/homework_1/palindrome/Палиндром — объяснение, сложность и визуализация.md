### Объяснение решения

Функция проверяет, является ли положительное целое число палиндромом, без использования строк.

Сначала исходное число сохраняется в переменной `num`, а его копия — в переменной `n`. Затем число `n` постепенно разбирается по цифрам справа налево.

Последняя цифра числа получается с помощью операции:

```python
n % 10
```

После этого последняя цифра удаляется с помощью целочисленного деления:

```python
n // 10
```

Из полученных цифр постепенно строится новое число `reversed_num`. Для этого уже накопленное значение умножается на `10`, после чего к нему добавляется очередная цифра:

```python
reversed_num = reversed_num * 10 + digit
```

Таким образом, после завершения цикла в `reversed_num` находится исходное число, записанное в обратном порядке.

Если `reversed_num == num`, число одинаково читается слева направо и справа налево, поэтому оно является палиндромом.

---

### Оценка сложности

Пусть `d` — количество цифр в числе.

На каждой итерации цикла удаляется одна цифра числа. Поэтому цикл выполняется `d` раз.

**Временная сложность:**

```text
O(d)
```

где `d` — количество цифр числа.

Если выражать сложность через само значение числа `n`, количество его цифр примерно равно `log10(n)`, поэтому также можно записать:

```text
O(log n)
```

**Дополнительная память:**

```text
O(1)
```

Алгоритм использует только несколько переменных независимо от размера входного числа.

### Визуализация работы алгоритма

Рассмотрим число:

```text
1221
```

В начале:

```text
nums = 1221
n = 1221
new = 0
```

Далее алгоритм выполняется пошагово:

| Шаг | `n` до операции | `digit = n % 10` | `n = n // 10` | `reversed_num = reversed_num * 10 + digit` |
|---:|---:|---:|---:|---:|
| 1 | 1221 | 1 | 122 | 1 |
| 2 | 122 | 2 | 12 | 12 |
| 3 | 12 | 2 | 1 | 122 |
| 4 | 1 | 1 | 0 | 1221 |

После завершения цикла:

```text
reversed_num = 1221
num = 1221
```

Проверяем:

```python
reversed_num == num
```

Получаем:

```text
True
```

Следовательно, число `1221` является палиндромом.

### Тесты

Использованы тесты для нескольких разных случаев:

```python
assert(is_palindrome(121) == True)
assert(is_palindrome(123) == False)
assert(is_palindrome(1221) == True)
assert(is_palindrome(1231) == False)
assert(is_palindrome(3) == True)
assert(is_palindrome(1000) == False)
assert(is_palindrome(505) == True)
```

Они проверяют:

- палиндром с нечётным количеством цифр;
- число, которое не является палиндромом;
- палиндром с чётным количеством цифр;
- случай, когда первая и последняя цифры совпадают, но число всё равно не является палиндромом;
- однозначное число;
- число с нулями в конце;
- палиндром с нулём внутри.
