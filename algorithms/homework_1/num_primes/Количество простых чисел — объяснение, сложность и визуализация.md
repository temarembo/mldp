### Объяснение решения

Функция должна найти количество простых чисел, которые строго меньше заданного числа `num`.

Алгоритм перебирает все числа от `2` до `num - 1`:

```python
for i in range(2, num):
```

Для каждого числа `i` предполагается, что оно простое:

```python
is_prime = True
```

После этого проверяется, существует ли у него делитель кроме `1` и самого числа.

Проверять все числа до `i - 1` необязательно. Если число составное, то хотя бы один из его делителей обязательно будет меньше или равен квадратному корню из этого числа.

Поэтому достаточно проверить делители в диапазоне:

```python
for j in range(2, int(i ** 0.5) + 1):
```

Если `i` делится на `j` без остатка:

```python
i % j == 0
```

значит, число составное и `is_prime` становится `False`.

Если после всех проверок `is_prime` осталось равным `True`, число является простым, поэтому счётчик увеличивается на `1`.

В конце функция возвращает количество найденных простых чисел.

---

### Почему достаточно проверять делители до квадратного корня

Пусть число `i` составное. Тогда его можно представить в виде:

```text
i = a × b
```

Если бы одновременно выполнялось:

```text
a > √i
b > √i
```

то:

```text
a × b > i
```

что невозможно.

Следовательно, если число составное, хотя бы один из его делителей обязательно будет не больше `√i`.

Например:

```text
35 = 5 × 7
√35 ≈ 5.9
```

Делитель `5` находится до квадратного корня, поэтому нет необходимости проверять `7`.

### Оценка сложности

Пусть `N` — входное число.

Внешний цикл перебирает примерно `N` чисел:

```text
2, 3, 4, ..., N - 1
```

Для каждого числа `i` внутренний цикл в худшем случае выполняет примерно `√i` проверок.

Поэтому временную сложность можно оценить как:

```text
O(N√N)
```

или:

```text
O(N^(3/2))
```

Алгоритм использует только несколько переменных:

```text
num_primes
i
j
is_prime
```

Размер используемой дополнительной памяти не зависит от `N`.

Поэтому пространственная сложность:

```text
O(1)
```

### Визуализация работы алгоритма

Рассмотрим:

```text
num = 10
```

Нужно проверить числа:

```text
2, 3, 4, 5, 6, 7, 8, 9
```

Работа алгоритма:

| `i` | Проверяемые делители | Результат проверки | Простое? | Счётчик |
|---:|---|---|:---:|---:|
| 2 | нет | делителей не найдено | да | 1 |
| 3 | нет | делителей не найдено | да | 2 |
| 4 | 2 | `4 % 2 == 0` | нет | 2 |
| 5 | 2 | `5 % 2 != 0` | да | 3 |
| 6 | 2 | `6 % 2 == 0` | нет | 3 |
| 7 | 2 | `7 % 2 != 0` | да | 4 |
| 8 | 2 | `8 % 2 == 0` | нет | 4 |
| 9 | 2, 3 | `9 % 3 == 0` | нет | 4 |

Таким образом, простые числа меньше `10`:

```text
2, 3, 5, 7
```

Их количество:

```text
4
```
