### Объяснение решения

Бинарное дерево поиска состоит из узлов `Node`.

Каждый узел хранит:

```python
value
left
right
```

где `left` — ссылка на левого ребёнка, а `right` — на правого.

Для BST выполняется правило:

```text
все значения слева < значение узла < все значения справа
```

В данной реализации предполагается, что дубликаты во входных данных отсутствуют.

---

## Вставка

Вставка выполняется рекурсивно.

Если текущего узла нет:

```python
if not root:
    return Node(value)
```

значит найдено место для нового элемента.

Если новое значение меньше текущего:

```python
value < root.value
```

оно вставляется в левое поддерево.

Иначе — в правое.

После изменения одного из поддеревьев текущий `root` возвращается обратно вверх по цепочке рекурсивных вызовов.

Например, последовательно вставим:

```text
8, 3, 10, 1, 6, 14, 4, 7, 13
```

Получится дерево:

```text
          8
        /   \
       3     10
      / \      \
     1   6      14
        / \     /
       4   7   13
```

---

## Обходы дерева

Используются обозначения:

```text
N — текущий узел
L — левое поддерево
R — правое поддерево
```

Шесть обходов отличаются только порядком этих трёх действий:

| Обход             | Порядок |
| ----------------- | ------- |
| preorder          | `N L R` |
| inorder           | `L N R` |
| postorder         | `L R N` |
| reverse preorder  | `N R L` |
| reverse inorder   | `R N L` |
| reverse postorder | `R L N` |

---

### Preorder

Порядок:

```text
Node → Left → Right
```

Для дерева:

```text
          8
        /   \
       3     10
      / \      \
     1   6      14
        / \     /
       4   7   13
```

результат:

```text
[8, 3, 1, 6, 4, 7, 10, 14, 13]
```

---

### Inorder

Порядок:

```text
Left → Node → Right
```

Результат:

```text
[1, 3, 4, 6, 7, 8, 10, 13, 14]
```

Для бинарного дерева поиска `inorder` возвращает значения в порядке возрастания.

---

### Postorder

Порядок:

```text
Left → Right → Node
```

Результат:

```text
[1, 4, 7, 6, 3, 13, 14, 10, 8]
```

---

### Reverse preorder

Порядок:

```text
Node → Right → Left
```

Результат:

```text
[8, 10, 14, 13, 3, 6, 7, 4, 1]
```

---

### Reverse inorder

Порядок:

```text
Right → Node → Left
```

Результат:

```text
[14, 13, 10, 8, 7, 6, 4, 3, 1]
```

Для BST этот обход возвращает значения в порядке убывания.

---

### Reverse postorder

Порядок:

```text
Right → Left → Node
```

Результат:

```text
[13, 14, 10, 7, 4, 6, 1, 3, 8]
```

---

## Визуализация рекурсивного обхода

Рассмотрим `preorder` для:

```text
        8
       / \
      3   10
     / \
    1   6
```

Правило:

```text
N L R
```

Сначала посещается `8`:

```text
result = [8]
```

Затем левое поддерево с корнем `3`:

```text
result = [8, 3]
```

После этого левый ребёнок `3`:

```text
result = [8, 3, 1]
```

У `1` детей нет, поэтому рекурсия возвращается к `3`.

Далее посещается правый ребёнок `6`:

```text
result = [8, 3, 1, 6]
```

После завершения левого поддерева возвращаемся к `8` и переходим вправо:

```text
result = [8, 3, 1, 6, 10]
```

Итог:

```text
[8, 3, 1, 6, 10]
```

## Оценка сложности

### Вставка

Сложность вставки зависит от высоты дерева `h`.

В общем случае:

```text
O(h)
```

Если дерево достаточно сбалансировано:

```text
O(log n)
```

В худшем случае дерево может превратиться почти в связный список:

```text
1
 \
  2
   \
    3
     \
      4
```

и тогда вставка занимает:

```text
O(n)
```

Рекурсивный стек также занимает:

```text
O(h)
```

---

### Обходы

Каждый обход посещает каждый узел ровно один раз.

Поэтому время:

```text
O(n)
```

где `n` — количество узлов.

Список результата содержит `n` значений:

```text
O(n)
```

Кроме того, рекурсия занимает:

```text
O(h)
```

памяти в стеке вызовов.

## Тесты

```python
tree = Tree()

for value in [8, 3, 10, 1, 6, 14, 4, 7, 13]:
    tree.insert(value)


assert tree.preorder() == [
    8, 3, 1, 6, 4, 7, 10, 14, 13
]

assert tree.inorder() == [
    1, 3, 4, 6, 7, 8, 10, 13, 14
]

assert tree.postorder() == [
    1, 4, 7, 6, 3, 13, 14, 10, 8
]

assert tree.reverse_preorder() == [
    8, 10, 14, 13, 3, 6, 7, 4, 1
]

assert tree.reverse_inorder() == [
    14, 13, 10, 8, 7, 6, 4, 3, 1
]

assert tree.reverse_postorder() == [
    13, 14, 10, 7, 4, 6, 1, 3, 8
]


# Пустое дерево
empty_tree = Tree()

assert empty_tree.preorder() == []
assert empty_tree.inorder() == []
assert empty_tree.postorder() == []
assert empty_tree.reverse_preorder() == []
assert empty_tree.reverse_inorder() == []
assert empty_tree.reverse_postorder() == []


# Дерево из одного элемента
single_tree = Tree()
single_tree.insert(5)

assert single_tree.preorder() == [5]
assert single_tree.inorder() == [5]
assert single_tree.postorder() == [5]
assert single_tree.reverse_preorder() == [5]
assert single_tree.reverse_inorder() == [5]
assert single_tree.reverse_postorder() == [5]


# Проверка BST через inorder
sorted_tree = Tree()

for value in [5, 2, 8, 1, 3, 7, 9]:
    sorted_tree.insert(value)

assert sorted_tree.inorder() == [1, 2, 3, 5, 7, 8, 9]
assert sorted_tree.reverse_inorder() == [9, 8, 7, 5, 3, 2, 1]
```

Тесты проверяют:

- все шесть обходов;
- дерево с несколькими уровнями;
- пустое дерево;
- дерево из одного элемента;
- корректность свойства BST через `inorder`;
- правильность обратной сортировки через `reverse_inorder`.
