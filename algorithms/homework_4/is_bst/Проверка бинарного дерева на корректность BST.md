### Объяснение решения

Для корректного бинарного дерева поиска должно выполняться правило:

```text
все значения в левом поддереве < значение текущего узла
все значения в правом поддереве > значение текущего узла
```

Важно проверять не только непосредственных детей узла, но и всё поддерево.

Например, дерево:

```text
        10
       /  \
      5    15
          /
         6
```

не является корректным BST.

На первый взгляд:

```text
5 < 10
15 > 10
6 < 15
```

и локальные сравнения выглядят правильными.

Но узел `6` находится в правом поддереве узла `10`, поэтому он должен быть больше `10`.

Условие:

```text
6 > 10
```

не выполняется.

---

### Идея алгоритма

При рекурсивном обходе для каждого узла передаётся допустимый диапазон его значения:

```text
min_value < node.value < max_value
```

Для корневого узла ограничений изначально нет, поэтому передаются:

```python
None, None
```

Если мы переходим в левое поддерево, значение текущего узла становится новой верхней границей:

```python
_is_bst(root.left, min_value, root.value)
```

Если переходим в правое поддерево, значение текущего узла становится новой нижней границей:

```python
_is_bst(root.right, root.value, max_value)
```

Например:

```text
        10
       /  \
      5    15
```

Для `10` допустим любой диапазон.

Для левого ребёнка `5`:

```text
значение < 10
```

Для правого ребёнка `15`:

```text
значение > 10
```

Если затем перейти в левое поддерево `15`, значение должно удовлетворять сразу двум ограничениям:

```text
10 < значение < 15
```

Таким образом учитываются ограничения не только от родителя, но и от всех его предков.

---

### Базовый случай рекурсии

Если текущего узла нет:

```python
if root is None:
    return True
```

пустое поддерево считается корректным BST.

---

### Проверка границ

Нижняя граница:

```python
if min_value is not None and root.value <= min_value:
    return False
```

Верхняя граница:

```python
if max_value is not None and root.value >= max_value:
    return False
```

Используются строгие сравнения, потому что в данной реализации предполагается, что дубликаты в BST не допускаются.

---

### Почему алгоритм корректен

Для каждого узла алгоритм проверяет все ограничения, которые возникают из его положения в дереве.

Узел в левом поддереве обязан быть меньше соответствующих предков, а узел в правом поддереве — больше.

Передача нижней и верхней границы гарантирует, что учитывается вся цепочка предков, а не только непосредственный родитель.

Если хотя бы один узел выходит за допустимый диапазон, функция возвращает `False`.

Если все узлы прошли проверку, возвращается `True`.

---

### Оценка сложности

Пусть `n` — количество узлов дерева.

Каждый узел проверяется ровно один раз, поэтому временная сложность:

```text
O(n)
```

Дополнительная память зависит от высоты дерева `h`, так как используется стек рекурсивных вызовов:

```text
O(h)
```

Для сбалансированного дерева:

```text
O(log n)
```

В худшем случае для вырожденного дерева:

```text
O(n)
```

---

### Визуализация

Рассмотрим дерево:

```text
        10
       /  \
      5    15
          /  \
         12   20
```

Проверка:

| Узел | Допустимый диапазон | Результат |
| ---: | ------------------- | --------- |
|   10 | без ограничений     | корректно |
|    5 | `< 10`              | корректно |
|   15 | `> 10`              | корректно |
|   12 | `10 < value < 15`   | корректно |
|   20 | `> 15`              | корректно |

Все ограничения выполнены:

```text
True
```

Теперь заменим `12` на `6`:

```text
        10
       /  \
      5    15
          /
         6
```

Для `6` допустимый диапазон:

```text
10 < value < 15
```

Но:

```text
6 <= 10
```

поэтому функция возвращает:

```text
False
```

### Тесты

```python
# Корректное BST
root = Node(
    10,
    Node(5),
    Node(15, Node(12), Node(20))
)

assert is_bst(root) is True


# Некорректное дерево:
# 6 находится в правом поддереве 10
root = Node(
    10,
    Node(5),
    Node(15, Node(6), Node(20))
)

assert is_bst(root) is False


# Один узел
root = Node(10)

assert is_bst(root) is True


# Пустое дерево
assert is_bst(None) is True


# Нарушение непосредственно у ребёнка
root = Node(
    10,
    Node(12),
    Node(15)
)

assert is_bst(root) is False


# Нарушение глубже в дереве
root = Node(
    20,
    Node(
        10,
        Node(5),
        Node(25)
    ),
    Node(30)
)

assert is_bst(root) is False
```

Тесты проверяют:

- корректное BST;
- нарушение свойства BST на глубоком уровне;
- дерево из одного узла;
- пустое дерево;
- нарушение непосредственно у ребёнка;
- случай, когда локально узел расположен правильно относительно родителя, но нарушает ограничение одного из предков.
