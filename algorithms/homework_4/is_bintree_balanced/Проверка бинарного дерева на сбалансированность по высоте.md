### Объяснение решения

Дерево считается сбалансированным по высоте, если для каждого узла выполняется условие:

```text
|высота левого поддерева - высота правого поддерева| <= 1
```

Важно проверить это условие не только для корня, но и для каждого узла дерева.

Алгоритм рекурсивно вычисляет высоту каждого поддерева.

Для пустого дерева высота считается равной:

```text
0
```

Высота непустого узла вычисляется как:

```text
max(высота левого поддерева,
    высота правого поддерева) + 1
```

Например:

```text
    5
   / \
  3   8
```

Высота узлов `3` и `8` равна `1`.

Поэтому высота узла `5`:

```text
max(1, 1) + 1 = 2
```

---

### Проверка баланса

После вычисления высот левого и правого поддеревьев проверяется:

```python
abs(left_height - right_height) > 1
```

Если разница больше `1`, дерево уже не является сбалансированным.

В этом случае вспомогательная функция возвращает:

```text
-1
```

Значение `-1` используется как специальный сигнал о том, что в текущем поддереве найден дисбаланс.

Если один из рекурсивных вызовов вернул `-1`, дальнейшее вычисление высоты не требуется:

```python
if left_height == -1:
    return -1
```

и аналогично для правого поддерева.

Основная функция:

```python
def is_balanced(root):
    return _height(root) != -1
```

возвращает `True`, если дисбаланс нигде не был найден.

---

### Почему алгоритм корректен

Для каждого узла алгоритм сначала проверяет его левое и правое поддеревья.

Если хотя бы одно из них уже несбалансировано, всё дерево с текущим узлом также не может быть сбалансированным.

Если оба поддерева сбалансированы, сравниваются их высоты.

Если:

```text
abs(left_height - right_height) <= 1
```

текущий узел удовлетворяет условию сбалансированности.

Так как проверка выполняется для каждого узла дерева, если функция завершилась без получения `-1`, условие выполняется для всего дерева.

### Визуализация

Рассмотрим дерево:

```text
        10
       /  \
      5    15
     / \     \
    3   7     20
```

Сначала рассматриваются листья:

```text
3, 7, 20
```

Их высота:

```text
1
```

Для узла `5`:

```text
left_height = 1
right_height = 1

разница = 0
```

Узел сбалансирован, его высота:

```text
2
```

Для узла `15`:

```text
left_height = 0
right_height = 1

разница = 1
```

Он тоже сбалансирован, его высота:

```text
2
```

Для корня `10`:

```text
left_height = 2
right_height = 2

разница = 0
```

Все узлы удовлетворяют условию, поэтому:

```text
True
```

---

Теперь рассмотрим:

```text
        10
       /
      5
     /
    3
   /
  1
```

Для узла `3`:

```text
left_height = 1
right_height = 0
```

Разница равна `1`, поэтому пока всё корректно.

Для узла `5`:

```text
left_height = 2
right_height = 0
```

Разница:

```text
2
```

Она больше `1`, поэтому функция возвращает:

```text
-1
```

и итоговый результат:

```text
False
```

### Оценка сложности

Пусть `n` — количество узлов дерева.

Каждый узел посещается не более одного раза, поэтому временная сложность:

```text
O(n)
```

Дополнительная память зависит от глубины рекурсии, то есть от высоты дерева `h`:

```text
O(h)
```

Для сбалансированного дерева:

```text
O(log n)
```

В худшем случае, если дерево вырождено в цепочку:

```text
O(n)
```

### Тесты

```python
# Сбалансированное дерево
root = Node(
    10,
    Node(5, Node(3), Node(7)),
    Node(15, None, Node(20))
)

assert is_balanced(root) is True


# Полностью сбалансированное дерево
root = Node(
    10,
    Node(5, Node(3), Node(7)),
    Node(15, Node(12), Node(20))
)

assert is_balanced(root) is True


# Несбалансированное дерево
root = Node(
    10,
    Node(
        5,
        Node(
            3,
            Node(1)
        )
    )
)

assert is_balanced(root) is False


# Дисбаланс находится не в корне
root = Node(
    10,
    Node(
        5,
        Node(
            3,
            Node(1)
        ),
        Node(7)
    ),
    Node(
        15,
        Node(12),
        Node(20)
    )
)

assert is_balanced(root) is False


# Один узел
root = Node(10)

assert is_balanced(root) is True


# Пустое дерево
assert is_balanced(None) is True


# Два уровня
root = Node(
    10,
    Node(5),
    None
)

assert is_balanced(root) is True
```

Тесты проверяют:

- обычное сбалансированное дерево;
- полностью заполненное дерево;
- сильно несбалансированное дерево;
- дисбаланс внутри одного из поддеревьев;
- дерево из одного узла;
- пустое дерево;
- допустимую разницу высот, равную `1`.
