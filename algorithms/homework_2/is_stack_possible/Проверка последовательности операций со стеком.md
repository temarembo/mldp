### Объяснение решения

Алгоритм имитирует работу обычного стека.

Элементы из `pushed` последовательно добавляются в стек в заданном порядке.

Переменная `j` хранит индекс следующего элемента из `popped`, который должен быть извлечён из стека.

После каждого добавления проверяется верхний элемент стека. Если он совпадает с `popped[j]`, этот элемент можно извлечь. После извлечения `j` увеличивается.

Проверка выполняется в цикле `while`, потому что после одного `pop` новый верхний элемент стека также может совпасть со следующим элементом из `popped`.

Если в конце удалось обработать все элементы `popped`, последовательность операций возможна и функция возвращает `True`. Иначе возвращается `False`.

### Почему алгоритм корректен

Элементы можно добавлять в стек только в порядке `pushed`.

При этом извлечь из стека можно только верхний элемент. Поэтому если верхушка совпадает со следующим требуемым элементом `popped`, её можно сразу удалить.

Если верхушка не совпадает, единственный возможный вариант — продолжить добавлять элементы из `pushed`.

Таким образом алгоритм в каждый момент выполняет единственное допустимое действие и точно имитирует возможную работу стека.

### Оценка сложности

Пусть `n` — количество элементов.

Каждый элемент:

- один раз добавляется в стек;
- не более одного раза удаляется из стека.

Поэтому временная сложность:

```text
O(n)
```

В худшем случае все элементы одновременно находятся в стеке, поэтому дополнительная память:

```text
O(n)
```

### Визуализация

Рассмотрим:

```text
pushed = 1 2 3 4 5
popped = 1 3 5 4 2
```

| Действие | Стек | Следующий элемент `popped` |
|---|---|---:|
| `push(1)` | `[1]` | 1 |
| `pop()` | `[]` | 3 |
| `push(2)` | `[2]` | 3 |
| `push(3)` | `[2, 3]` | 3 |
| `pop()` | `[2]` | 5 |
| `push(4)` | `[2, 4]` | 5 |
| `push(5)` | `[2, 4, 5]` | 5 |
| `pop()` | `[2, 4]` | 4 |
| `pop()` | `[2]` | 2 |
| `pop()` | `[]` | — |

Все элементы `popped` удалось получить в необходимом порядке, поэтому результат:

```text
True
```

### Тесты

Тесты проверяют:

- пример из условия;
- прямой порядок извлечения;
- полностью обратный порядок;
- невозможные последовательности;
- минимальный случай из одного элемента;
- небольшие последовательности из двух элементов.
