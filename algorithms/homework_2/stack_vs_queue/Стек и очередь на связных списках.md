### Объяснение решения

Связный список состоит из узлов `Node`.

Каждый узел хранит:

```python
self.value
```

— значение элемента, и:

```python
self.next
```

— ссылку на следующий узел.

Последний узел имеет:

```python
self.next = None
```

---

## Стек

Стек работает по принципу **LIFO** — последний добавленный элемент извлекается первым.

Пример:

```text
push(10)
push(20)
push(30)
```

Стек будет выглядеть так:

```text
head
 ↓
[30] -> [20] -> [10] -> None
```

### `push`

При добавлении нового элемента создаётся новый узел:

```python
new_node = Node(value)
```

Он начинает ссылаться на старую вершину стека:

```python
new_node.next = self.head
```

После этого новый узел становится новой вершиной:

```python
self.head = new_node
```

Например:

```text
До push(40):

head
 ↓
[30] -> [20] -> [10]

После push(40):

head
 ↓
[40] -> [30] -> [20] -> [10]
```

### `pop`

При удалении элемента сначала запоминается текущая вершина:

```python
head = self.head
```

Если стек пуст:

```python
head is None
```

возвращается `None`.

Иначе вершина передвигается на следующий узел:

```python
self.head = head.next
```

а значение старой вершины возвращается.

---

## Очередь

Очередь работает по принципу **FIFO** — первый добавленный элемент извлекается первым.

Очередь хранит две ссылки:

```python
self.head
self.tail
```

`head` указывает на первый элемент очереди, а `tail` — на последний.

Например:

```text
head              tail
 ↓                  ↓
[10] -> [20] -> [30] -> None
```

### `enqueue`

При добавлении элемента создаётся новый узел.

Если очередь пустая:

```text
head -> None
tail -> None
```

новый узел одновременно становится и первым, и последним:

```python
self.head = new_node
self.tail = new_node
```

Если очередь уже содержит элементы, старый `tail` начинает ссылаться на новый узел:

```python
self.tail.next = new_node
```

после чего `tail` перемещается на новый узел:

```python
self.tail = new_node
```

Пример:

```text
До enqueue(40):

head              tail
 ↓                  ↓
[10] -> [20] -> [30]

После enqueue(40):

head                       tail
 ↓                           ↓
[10] -> [20] -> [30] -> [40]
```

### `dequeue`

Из очереди удаляется элемент, на который указывает `head`.

Если очередь пустая, возвращается `None`.

Иначе:

```python
self.head = head.next
```

После этого старый первый элемент больше не принадлежит очереди.

Есть важный граничный случай: если удалялся последний элемент, после операции:

```python
self.head is None
```

Тогда необходимо также сделать:

```python
self.tail = None
```

чтобы очередь снова находилась в корректном пустом состоянии.

---

### Оценка сложности

#### Стек

`push`:

```text
O(1)
```

Для добавления элемента не требуется проходить по связанному списку.

`pop`:

```text
O(1)
```

Удаляется только первый узел.

#### Очередь

`enqueue`:

```text
O(1)
```

Так как хранится ссылка `tail`, последний элемент доступен напрямую.

`dequeue`:

```text
O(1)
```

Удаляется первый узел, доступный через `head`.

---

### Память

Пусть в структуре хранится `n` элементов.

Каждый элемент представлен отдельным объектом `Node`, поэтому память:

```text
O(n)
```

Каждый узел хранит значение и одну ссылку на следующий узел.

### Визуализация работы стека

Создадим стек:

```python
stack = Stack()
```

Изначально:

```text
head -> None
```

Выполним:

```python
stack.push(10)
```

Получаем:

```text
head
 ↓
[10] -> None
```

Затем:

```python
stack.push(20)
```

```text
head
 ↓
[20] -> [10] -> None
```

Затем:

```python
stack.push(30)
```

```text
head
 ↓
[30] -> [20] -> [10] -> None
```

Вызов:

```python
stack.pop()
```

возвращает:

```text
30
```

После этого:

```text
head
 ↓
[20] -> [10] -> None
```

---

### Визуализация работы очереди

Создадим очередь:

```python
queue = Queue()
```

Выполним:

```python
queue.enqueue(10)
queue.enqueue(20)
queue.enqueue(30)
```

Получаем:

```text
head              tail
 ↓                  ↓
[10] -> [20] -> [30] -> None
```

Теперь вызываем:

```python
queue.dequeue()
```

Возвращается:

```text
10
```

Очередь становится:

```text
head       tail
 ↓           ↓
[20] -> [30] -> None
```

Следующий вызов:

```python
queue.dequeue()
```

вернёт:

```text
20
```
