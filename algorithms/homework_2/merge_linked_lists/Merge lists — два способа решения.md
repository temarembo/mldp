### Объяснение решения

Оба входных односвязных списка уже отсортированы.

Поэтому достаточно сравнивать текущие узлы `list1` и `list2` и каждый раз присоединять к результату узел с меньшим значением.

После добавления узла соответствующий указатель сдвигается на следующий элемент.

Когда один из списков заканчивается, остаток второго списка можно целиком присоединить к результату, потому что он уже отсортирован.

Важно, что новые узлы для результата не создаются: итоговый список составляется переиспользованием узлов исходных списков.

---

### Способ 1: с фиктивным элементом

Создаётся дополнительный узел:

```python
dummy = Node(0)
```

Он не является частью результата, а используется только для удобства построения списка.

Указатель `tail` всегда показывает на последний узел объединённого списка.

После завершения работы голова результата находится в:

```python
dummy.next
```

Преимущество этого способа в том, что не нужно отдельно обрабатывать выбор первого элемента результата.

---

### Способ 2: без фиктивного элемента

В этом варианте сначала отдельно определяется первый узел результирующего списка.

Сравниваются первые элементы `list1` и `list2`, и меньший из них становится:

```python
head
```

После этого алгоритм работает так же, как в первом варианте: `tail` указывает на последний добавленный узел, а элементы двух списков последовательно сливаются.

Этот способ не использует дополнительный фиктивный узел, но требует отдельной обработки начала списка.

---

### Визуализация

Пусть:

```text
list1 = 1 -> 2 -> 4
list2 = 1 -> 3 -> 4
```

Сравниваем первые элементы:

```text
1 и 1
```

Берём первый `1`:

```text
result: 1
list1: 2 -> 4
list2: 1 -> 3 -> 4
```

Следующее сравнение:

```text
2 и 1
```

Берём `1` из второго списка:

```text
result: 1 -> 1
list1: 2 -> 4
list2: 3 -> 4
```

Дальше:

```text
2 и 3
```

Берём `2`:

```text
result: 1 -> 1 -> 2
```

Затем:

```text
4 и 3
```

Берём `3`:

```text
result: 1 -> 1 -> 2 -> 3
```

Остаются:

```text
list1: 4
list2: 4
```

Они последовательно добавляются:

```text
1 -> 1 -> 2 -> 3 -> 4 -> 4
```

---

### Оценка сложности

Пусть:

```text
n — количество узлов в list1
m — количество узлов в list2
```

Каждый узел обрабатывается не более одного раза.

Поэтому временная сложность:

```text
O(n + m)
```

Дополнительная память:

```text
O(1)
```

Потому что алгоритм использует только несколько ссылок и не создаёт новый список из новых узлов.

В варианте с фиктивным элементом создаётся только один дополнительный узел, что также считается `O(1)` памяти.

---

### Что проверяют тесты

Тесты включают:

- пример из условия;
- два пустых списка;
- один пустой список;
- списки из одного элемента;
- случай, когда все элементы одного списка меньше элементов другого;
- чередующиеся элементы;
- повторяющиеся значения.
