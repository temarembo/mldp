# Backend

Домашние задания курса Backend в общем репозитории магистратуры.
Каждое задание находится в собственной папке `hwN`.

- [ДЗ1: API модерации объявлений](hw1/README.md).

## Окружение первого ДЗ

Из папки `backend`:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r hw1/requirements.txt
```

## Тесты первого ДЗ

Из папки `backend` с активированным окружением:

```bash
pytest -v
```

Эквивалентный запуск — `python -m pytest -v`. Обе команды также работают из
папки `hw1`. Конфигурация `pytest.ini` добавляет `hw1` в путь импортов и
ограничивает поиск тестов первым ДЗ при запуске из папки курса.

## Запуск первого ДЗ

```bash
cd hw1
fastapi dev
```

Эквивалентная команда запуска — `python -m fastapi dev`.

Контракт API, примеры запросов и ограничения описаны в [README первого ДЗ](hw1/README.md).
